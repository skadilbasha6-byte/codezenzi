# Codezenzi

Real-time coding error detection, explanations and AI code generation.

## Run locally
1. `pnpm install`
2. Copy `.env.example` to `.env.local` and add your `GOOGLE_GENERATIVE_AI_API_KEY`
3. `pnpm dev`

## Deploy
Add `GOOGLE_GENERATIVE_AI_API_KEY` as an environment variable on your hosting platform, then deploy.
